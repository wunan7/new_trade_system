## 快速了解

**这是什么？**  
一套面向中国A股市场的量化交易决策系统，通过44个量化因子 + 4大策略 + 5类事件驱动信号 + 完整风控体系，在 3 年历史回测中取得了年化 +7.93% 的收益（沪深300同期 +8.56%），**超额收益 +16.04%**，夏普比率 0.61，最大回撤仅 11.52%。

**核心亮点**：
- 真实交易约束下的回测（涨跌停/停牌不可交易）
- 从 -19.86% 到 +24.60% 的 7 次迭代优化历程
- 数据驱动的因子有效性评估（IC/IR 分析）
- 完整的版本归档与可复现机制
