## 4.2 四大策略详解

### 策略一：价值策略

| 项目 | 内容 |
|------|------|
| **核心逻辑** | 发现被低估的优质公司，等待价值回归 |
| **硬性过滤** | ROE > 12% + 股息率 ≥ 2% + 资产负债率 < 60% |
| **二次过滤** | PB 分位 < 30%（最低估值的30%） |
| **评分权重** | PB反向30% + ROE归一化30% + 股息率20% + 现金流/利润20% |
| **置信度加成** | 商誉比率低 +0.1、应计比率为负 +0.1 |
| **选股数量** | Top 20 |
| **持仓周期** | 60天 |
| **适用市场** | 震荡市、熊市后期 |

### 策略二：成长策略

| 项目 | 内容 |
|------|------|
| **核心逻辑** | 捕捉高成长、高盈利能力的公司 |
| **硬性过滤** | 利润增速 > 30% + 营收增速 > 20% + ROE > 8% |
| **评分权重** | 利润增速40% + 营收增速30% + ROE20% + 毛利率10% |
| **置信度加成** | 净利率 > 15% +0.1、营收增速 > 40% +0.1 |
| **选股数量** | Top 20 |
| **持仓周期** | 60天 |
| **适用市场** | 牛市、结构性行情 |

### 策略三：动量策略

| 项目 | 内容 |
|------|------|
| **核心逻辑** | 强者恒强，跟随趋势买入 |
| **硬性过滤** | 20d动量分位 ≥ 50% + 60d动量分位 ≥ 50% + 绝对涨幅 ≤ 50% + 量比 ≥ 0.5 |
| **评分权重** | 20d动量35% + 60d动量25% + 量比20% + ADX20% |
| **置信度调节** | OBV斜率为正 +0.1、为负 -0.1 |
| **选股数量** | Top 15 |
| **持仓周期** | 10天（短线） |
| **适用市场** | 趋势行情 |

### 策略四：事件驱动（5类事件）

| 事件类型 | 数据量 | 回溯期 | 持仓 | 逻辑 | 每日上限 |
|---------|:------:|:-----:|:----:|------|:-------:|
| **龙虎榜** | 96K条 | 5天 | 7天 | 机构净买入>500万 + 5天内出现2次 | 10 |
| **业绩超预期** | 25K条 | 7天 | 10天 | 业绩预告变动幅度>0，confidence按幅度缩放 | 5 |
| **公司回购** | 4K条 | 10天 | 15天 | 回购金额越大→confidence越高 | 5 |
| 业绩不及预期 | 19K条 | — | — | 仅作为负面过滤器（不产生买入信号） | — |
| 限售解禁 | 15K条 | — | — | 仅作为负面过滤器 | — |

**信号数上限设计**：每类事件每天最多产生固定数量的信号，防止单一事件类型挤占其他策略的信号配额。这是从失败实验中学到的关键教训（详见第6章）。

## 4.3 市场状态检测器

基于沪深300指数和全市场数据的**6维评分系统**：

| 维度 | 数据源 | 计算方法 | 评分 |
|------|--------|---------|------|
| 趋势 | CSI300收盘价 | 价格vs MA60 + 20d动量 | -2 ~ +2 |
| 波动率 | CSI300日收益 | 20d波动率 vs 60d波动率 | 0 ~ +1 |
| 市场宽度 | factor_cache | 20d动量为正的股票占比 | -1 ~ +1 |
| 北向资金 | money_flow | 5日累计北向净买入 | -1 ~ +1 |
| 换手率 | CSI300 | 当前换手率在60日分位 | 0 ~ +1 |
| 涨跌停比 | stock_daily | (涨停数-跌停数)/总数 | -1 ~ +1 |

**分类规则**：
- 趋势分 = 趋势 + 宽度 + 北向：≥3 → BULL，≤-3 → BEAR，其余 → NEUTRAL
- 波动分 = 波动率 + 换手率 + 涨跌停比：≥2 → HIGH，其余 → LOW
- 组合：{BULL/NEUTRAL/BEAR} × {HIGH/LOW} = 6种状态

**3年回测期间市场状态分布**：
```
neutral_low (震荡低波): 377天 (52%)  ← 主战场
bear_low    (熊市低波): 202天 (28%)
bull_low    (牛市低波): 141天 (19%)
neutral_high/bull_high:   6天 (1%)   ← 极少
```

## 4.4 信号聚合逻辑

当同一只股票被多个策略选中时：

1. **加权合并**：direction 和 confidence 按市场状态权重加权平均
2. **标记为 multi**：strategy 字段标记为 "multi"（多策略共识信号）
3. **负信号过滤**：聚合后 direction ≤ 0 的信号被剔除（不做空）

**V6-pure 策略信号分布**：
```
event:    865 (47%)  ← 事件驱动是最大信号来源
momentum: 340 (19%)
value:    335 (18%)
growth:   260 (14%)
multi:     29 (2%)   ← 多策略共识（通常质量最高）
```
