# 1. 系统概览与核心指标

## 1.1 项目定位

A股智能交易决策系统是一套**多因子 + 多策略 + 事件驱动**的量化选股与风控体系，面向中国A股全市场（5000+只股票），以 Python 为核心技术栈，PostgreSQL 为数据存储后端，实现从数据采集到因子计算、策略信号生成、风险控制的完整流水线。

**系统不预测价格**，而是通过量化因子评估股票的相对吸引力，结合市场状态自适应的策略权重，生成带有置信度和止损参数的标准化交易信号。

## 1.3 技术栈

| 组件 | 技术选型 |
|------|---------|
| 核心语言 | Python 3.11+ |
| 数据库 | PostgreSQL 15+（双库架构） |
| ORM | SQLAlchemy 2.0+ |
| 数据处理 | Pandas + NumPy + SciPy |
| 配置管理 | Pydantic-settings + python-dotenv |
| 日志 | loguru |
| 数据源 | AKShare（免费）+ TrendRadar（自研舆情系统） |
