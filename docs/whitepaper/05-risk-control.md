# 5. 风险控制体系

## 5.1 四层风控架构

```
策略信号 → [前置约束] → [仓位定量] → [持仓监控] → [回撤熔断]
              │             │            │             │
         涨跌停/ST/      Kelly公式     止损/止盈      四级预警
         流动性/行业      波动率调整    移动止盈       自动减仓
```

## 5.2 前置硬性约束

| 约束规则 | 阈值 | 来源 |
|---------|------|------|
| 涨停板不可买入 | 收盘价 ≥ 涨停价 | trade_constraints 表 |
| 停牌不可交易 | is_suspended = true | trade_constraints 表 |
| ST 排除 | is_st = true | trade_constraints 表 |
| 单股仓位上限 | ≤ 15% | 硬编码 |
| 单行业上限 | ≤ 30% | 申万一级行业 |
| 上市日期 | ≥ 60个交易日 | stock_info.list_date |
| 流动性 | 20日均成交额 ≥ 500万 | stock_daily.amount |

## 5.3 仓位定量引擎（三级控制）

**Level 1：总仓位上限**（由市场状态决定）

| 市场状态 | 最大仓位 |
|---------|:-------:|
| 牛市低波 | 90% |
| 牛市高波 | 80% |
| 震荡低波 | 60% |
| 震荡高波 | 50% |
| 熊市低波 | 40% |
| 熊市高波 | 20% |

**Level 2：策略配额**（由策略权重决定）

每只股票的最大仓位 = min(策略权重, 15%硬上限)

**Level 3：个股定量（半Kelly公式）**

```
个股仓位 = min(
    Kelly仓位 × 0.5,              // 半Kelly，保守
    信号强度 × 策略配额上限,       // confidence越高仓位越大
    1 / 波动率调整,                // 高波动→小仓位
    15% 硬上限
)
```

## 5.4 持仓监控：策略专属止损

| 策略 | 固定止损 | 止盈触发 | 移动止盈 | 最大持仓天数 |
|------|:-------:|:-------:|:-------:|:-----------:|
| 动量 | -5% | +10% | 5% 回撤 | 10天 |
| 成长 | -8% | +15% | 4% 回撤 | 60天 |
| 价值 | -12% | +20% | 4% 回撤 | 60天 |
| 事件 | -8% | +15% | 4% 回撤 | 60天 |

**移动止盈三档递进**：
- 盈利 > 40% → 3% 回撤即止盈
- 盈利 > 20% → 4% 回撤即止盈
- 盈利 > 10% → 5% 回撤即止盈

**ATR 动态止损**：初始止损 = max(固定止损线, 入场价 - 2×ATR)，取更紧的一个。

## 5.5 卖出约束（V6新增）

| 约束 | 行为 |
|------|------|
| 跌停板不可卖出 | 延迟到下一个非跌停日卖出 |
| 停牌不可卖出 | 延迟到复牌日卖出 |

## 5.6 回撤熔断机制

| 回撤等级 | 触发条件 | 响应 |
|---------|---------|------|
| 正常 | 回撤 < 12% | 正常交易 |
| 黄色预警 | 12% ≤ 回撤 < 15% | 禁止新建仓，仅管理现有持仓 |
| 橙色预警 | 15% ≤ 回撤 < 20% | 减仓至 50% 以下 |
| 红色预警 | 20% ≤ 回撤 < 25% | 减仓至 20% 以下 |
| 熔断 | 回撤 ≥ 25% | 全部清仓，进入观察模式 |

## 5.7 交易成本模型

| 费用项 | 比例 | 适用 |
|--------|:----:|------|
| 佣金 | 万2.5（单边） | 买入+卖出 |
| 印花税 | 千1 | 仅卖出 |
| 滑点 | 万2 | 买入+卖出 |
| **单笔交易总成本** | **~0.12%** | — |
