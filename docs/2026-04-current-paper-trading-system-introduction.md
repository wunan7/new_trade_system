# 当前运行中的模拟盘交易系统详解

**文档日期**: 2026-04-16  
**系统名称**: A股智能交易决策系统（new_solution）  
**当前生产/模拟盘版本**: **V6-pure**  
**运行方式**: 每交易日 19:30 自动执行  
**状态**: 模拟盘持续运行中  

---

## 一、这是一套什么系统？

这是一套面向 **中国A股市场** 的量化交易决策系统。它不是单纯依赖某一个模型去“预测明天涨跌”，而是通过：

- 多源市场数据
- 多因子评分体系
- 多策略并行选股
- 风险控制与仓位管理
- 真实交易约束（涨跌停/停牌）

来生成每日的标准化交易信号，并在模拟盘中自动执行。

它的目标不是追求极端高频，也不是依赖单一“神因子”或单一“神策略”，而是建立一套：

> **可回测、可解释、可版本化、可持续迭代的交易系统。**

---

## 二、当前在跑的是哪个版本？

当前正在跑模拟盘的版本是：

# **V6-pure**

这是目前系统中**最适合真实运行**的一版。

### 为什么不是别的版本？

我们历史上做过多个版本：
- V1：基础版，收益为负
- V2：补全数据后修复价值策略
- V3：修复事件驱动单位错误和舆情时序，第一次形成可用系统
- V5c：引入 IC/IR 置信度调整，提升交易质量
- V6：在 V5c 基础上加入真实交易约束、5类事件驱动扩展，效果最好
- **V6-pure**：在 V6 基础上，进一步剥离掉“遗留的 IC 置信度调整”，保留更清晰、更透明、更可解释的主逻辑，用作当前生产/模拟盘版本

也就是说：

- **V6** = 事件扩展 + 真实交易约束 + IC 调整
- **V6-pure** = 事件扩展 + 真实交易约束（不含 IC 调整）

### 当前为什么选 V6-pure？

因为它：
1. 逻辑更清晰透明；
2. 与“系统当前主策略框架”一致，没有额外的遗留加权逻辑；
3. 结果仍然很强；
4. 更适合作为对外说明和后续持续迭代的生产基线。

## 四、系统用了哪些数据？

系统的底层数据来自两个 PostgreSQL 数据库：

### 1. finance 数据库（行情 + 财务 + 估值 + 资金流 + 事件）

主要表：
- `stock_daily`：A股日行情（OHLCV）
- `stock_valuation`：PE / PB / PS / 市值等估值数据
- `financial_income` / `financial_balance` / `financial_cashflow`
- `financial_summary`：常用财务摘要指标
- `money_flow`：北向资金、主力资金、融资融券数据
- `events`：龙虎榜、业绩超预期、回购、解禁等事件数据
- `trade_constraints`：涨跌停价格、停牌标记、ST状态、次新股标记
- `macro_data`：宏观数据（PMI、LPR、SHIBOR、USD/CNY等）
- `factor_cache`：因子缓存结果

### 2. finance_public_opinion 数据库（TrendRadar 舆情系统）

主要表：
- `stock_sentiment_daily`：个股日度情绪聚合
- `ai_analysis_results`：AI 盘前/盘后分析
- `sector_impacts_json`：板块级信号
- `market_sentiment_score`：市场情绪评分
- `risk_level`：市场风险等级
- `news_items` / `rss_items`：原始新闻源

### 数据源特点

| 数据类型 | 来源 | 特点 |
|---------|------|------|
| 日行情/财务/估值 | AKShare + 自建 finance_data | 免费、结构化、可持续更新 |
| 资金流 | money_flow 表 | 已补全 2022 年以来历史 |
| 事件数据 | events 表 | 已扩展到多类型事件 |
| 舆情数据 | TrendRadar | 自研 AI 舆情系统 |
| 宏观数据 | macro_data 表 | 市场状态判断的宏观维度输入 |

## 五、系统用了哪些“模型”？

这里的“模型”不是单一机器学习黑盒模型，而是三层：

### 1. 因子模型（Factor Model）
系统先对全市场股票计算 44 个因子，再通过因子组合得到每只股票在不同策略维度下的吸引力。

### 2. 策略评分模型（Scoring Model）
每个策略都有自己的评分函数，例如：
- 价值策略：PB、ROE、股息率、现金流
- 成长策略：利润增速、营收增速、ROE、毛利率
- 动量策略：20日/60日动量、量比、ADX
- 事件驱动：龙虎榜、业绩超预期、回购等事件信号

这些评分不是神经网络，而是**显式、可解释的打分函数**。

### 3. 风险模型（Risk Model）
最后通过：
- 交易约束过滤
- Kelly 仓位控制
- 策略止损止盈
- 回撤熔断

把原始信号变成最终可执行的交易决策。

因此，这套系统更准确的说法是：

> **多因子 + 多策略 + 风险约束的量化决策系统**

而不是单纯的机器学习预测器。

## 七、当前版本用了哪些策略？

当前运行中的 V6-pure 使用 **4 个主策略**。

### 1. 价值策略（Value）
**目标**：找出低估值、现金流好、股息率高的股票

**主要条件**：
- ROE > 12%
- 股息率 ≥ 2%
- 资产负债率 < 60%
- PB 处于候选集中最低 30% 的区间

**持仓周期**：60天

**适用市场**：震荡市、熊市后期

---

### 2. 成长策略（Growth）
**目标**：寻找高增长且盈利能力强的公司

**主要条件**：
- 利润增速 > 30%
- 营收增速 > 20%
- ROE > 8%

**持仓周期**：60天

**适用市场**：牛市、结构性行情

---

### 3. 动量策略（Momentum）
**目标**：捕捉短中期趋势延续

**主要条件**：
- 20日动量分位 ≥ 50%
- 60日动量分位 ≥ 50%
- 量比 ≥ 0.5
- 避免极端涨幅股

**持仓周期**：10天

**适用市场**：趋势性市场

---

### 4. 事件驱动策略（Event-Driven）
这是当前 V6-pure 中最有特色、也是贡献最大的策略之一。

当前使用 5 类事件数据，其中 3 类用于生成正向交易信号，2 类作为负面过滤逻辑：

#### 正向事件
1. **龙虎榜**
   - 条件：净买入 > 500万元，且 5 天内出现至少 2 次
   - 持仓周期：7天

2. **业绩超预期（earnings_beat）**
   - 根据业绩预告变动幅度提升置信度
   - 持仓周期：10天

3. **公司回购（buyback）**
   - 根据回购金额和回购计划强度生成信号
   - 持仓周期：15天

#### 负面事件（用于过滤，不直接买入）
4. **业绩不及预期（earnings_miss）**
5. **限售解禁（lock_up_expire）**

这套事件策略在 V6 中是**最重要的收益来源之一**。

## 八、市场状态是怎么判断的？

系统不是在任何市场状态下都用同样的策略权重，而是先判断市场当前处于什么环境，再动态分配各策略权重。

### 当前使用 6 维市场状态检测：
1. 趋势（价格 vs MA60 + 动量）
2. 波动率（20日 vs 60日）
3. 市场宽度（上涨股票占比）
4. 北向资金趋势
5. 换手率活跃度
6. 涨跌停比率

### 输出 6 种市场状态：
- bull_low
- bull_high
- neutral_low
- neutral_high
- bear_low
- bear_high

### 当前 3 年回测里最常见状态：
- `neutral_low`：约 52%
- `bear_low`：约 28%
- `bull_low`：约 19%

这意味着系统大多数时间都运行在“震荡偏弱”环境下，因此：
- value 和 event 更常成为主要策略
- momentum 权重相对受压制

## 九、风险控制怎么做？

### 1. 交易前约束
- ST 不买
- 停牌不买
- 涨停不买
- 次新股（<60交易日）不买
- 流动性不足不买
- 单股仓位上限 15%
- 单行业上限 30%

### 2. 仓位管理
- 总仓位上限由市场状态决定（20%~90%）
- 个股仓位由 Kelly 公式、信号置信度、波动率共同决定

### 3. 止损止盈
- 动量：-5%
- 成长：-8%
- 价值：-12%
- 事件：-8%
- 同时有 ATR 动态止损和移动止盈

### 4. 卖出约束（V6 起非常关键）
- 跌停时不能卖出，只能顺延到下一个可卖日
- 停牌时不能卖出，只能等待复牌

这一点非常重要，因为它让回测结果更接近真实 A 股交易环境。

## 十、当前模拟盘怎么运行？

### 运行机制
- 每个交易日 **19:30** 自动运行
- 上游数据先更新，再计算因子、生成信号、执行模拟交易
- 非交易日自动跳过（已接入交易日历判断）

### 当前状态
- 模拟盘已稳定连续运行
- 非交易日 / 节假日能够自动识别并跳过
- 交易成本已计入：佣金、印花税、滑点

### 4月首月表现
- 4月首个交易日净值：1,000,343
- 4月末净值：1,005,018
- 月度收益：约 **+0.47%**

这说明系统已经从“只能回测”进入到了“**能真实连续跑模拟盘**”的阶段。

## 十一、为什么当前版本能取得这个结果？

V6-pure 当前能达到 +24.60% 的 3 年总收益，不是靠某一个点，而是靠几次关键演化叠加：

1. **估值数据补全** → 价值策略从瘫痪恢复
2. **事件驱动单位修复** → 龙虎榜策略真正生效
3. **舆情 T-1 修复** → 舆情因子正常接入
4. **交易约束接入** → 结果更真实
5. **5类事件扩展** → 事件策略从单一龙虎榜扩展成组合型事件策略
6. **事件信号限额控制** → 防止事件驱动挤压其他策略

换句话说，当前版本不是“凭空变好”，而是：

> **通过持续修复数据问题、交易约束问题、事件策略问题，逐步逼近真实市场中的可执行状态。**

## 十二、当前版本的边界

这套系统已经能稳定运行，但它还不是终点。

当前仍然存在的限制包括：
- 还没有接入 LLM 信号仲裁层
- 还没有技术择时策略（原设计中的第5个策略）
- 还没有完整的板块情绪因子注入策略层
- 4 月模拟盘暴露出交易频率和小额交易过多的问题

所以现在这套系统更准确的描述是：

> **它已经是一套可运行、可回测、可迭代、具备真实交易约束的中高级量化模拟交易系统。**

而不是“最终形态”。
