# 2. 六层架构设计

## 2.1 架构总览

```
┌─────────────────────────────────────────────────────┐
│ Layer 6: 人机交互层                                  │
│ CLI日志 / 定时任务 / 版本归档                         │
├─────────────────────────────────────────────────────┤
│ Layer 5: LLM决策融合层（规划中）                      │
│ 信号仲裁 / 报告生成 / 风险预警                        │
├─────────────────────────────────────────────────────┤
│ Layer 4: 风险控制与仓位管理                           │
│ 止损/止盈 / Kelly仓位 / 回撤熔断 / 涨跌停约束         │
├─────────────────────────────────────────────────────┤
│ Layer 3: 多策略信号生成                               │
│ 价值 / 成长 / 动量 / 事件驱动(5类)                    │
│ 市场状态检测(6维) → 动态策略权重                       │
├─────────────────────────────────────────────────────┤
│ Layer 2: 因子计算与特征工程                           │
│ 44个因子: 技术(17) + 基本面(17) + 资金(7) + 舆情(3)   │
│ MAD极值处理 + Z-Score标准化 + IC/IR评估               │
├─────────────────────────────────────────────────────┤
│ Layer 1: 数据采集与存储                               │
│ 双PostgreSQL数据库 / 3500万行 / 15类数据源            │
│ AKShare(免费行情) + TrendRadar(AI舆情) + 宏观指标     │
└─────────────────────────────────────────────────────┘
```

## 2.2 每日执行流水线

```
18:00  finance_data 日更新（行情+估值+指数）     ← 已有自动化
19:00  money_flow / events / macro_data 更新      ← 已有自动化
19:30  ┌─ Step 1: 因子计算（44因子 × 5000+股, ~90秒）
       ├─ Step 2: 信号生成（4策略 + 市场状态检测, ~5秒）
       ├─ Step 3: 加载组合持仓
       ├─ Step 4: 回撤监控 + 市场状态判断
       ├─ Step 5: 止损/止盈检查 → 卖出信号
       ├─ Step 6: 涨跌停/停牌约束过滤
       ├─ Step 7: Kelly仓位定量 → 买入订单
       ├─ Step 8: 模拟执行 + NAV记录
       └─ 完成（总耗时 ~2分钟）
22:00  TrendRadar 因子聚合（板块信号→个股情绪）    ← TrendRadar自动化
```

## 2.4 层间接口规范

### 信号标准格式（Layer 3 → Layer 4）

```python
Signal(
    trade_date   = date(2026, 4, 10),
    stock_code   = "600519",
    strategy     = "value",        # value / growth / momentum / event / multi
    direction    = 0.72,           # 0.0 ~ 1.0（做多强度）
    confidence   = 0.65,           # 0.0 ~ 1.0（置信度）
    holding_period = 60,           # 建议持仓天数
    entry_price  = 1850.00,        # 入场价格
    stop_loss    = 1628.00,        # 止损价格
    take_profit  = 2220.00,        # 止盈触发价
    factors      = {"pb": 8.5, "roe": 22.0, ...}  # 驱动因子
)
```
